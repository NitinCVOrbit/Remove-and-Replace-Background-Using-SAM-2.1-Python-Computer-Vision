# 🪄 Remove and Replace Background Using SAM 2.1

Build an AI-powered image background replacement system using **SAM 2.1, Python, and OpenCV**.

Select a subject using simple point prompts, generate accurate segmentation masks, remove the original background, and replace it with a new image.

### 🚀 Features
- Point-based subject selection.
- AI-powered segmentation using SAM 2.1.
- Automatic background removal.
- Replace backgrounds with custom images.
- Smooth mask edges for natural results.

### 🛠️ Technologies
Python | SAM 2.1 | OpenCV | NumPy | Matplotlib | Ultralytics
